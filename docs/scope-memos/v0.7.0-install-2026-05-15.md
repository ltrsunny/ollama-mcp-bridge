## 1. Problem — the adoption funnel

v0.6.0 needs the user to manually: brew-tap+install oMLX, start service, install bridge,
`download-models` (~7.5 GB), wire MCP config, copy the enforce hook. Six manual steps, each a drop-off
/ a thing done wrong. Honour-system fails at install for the same reason it failed for bridge-usage
(why the enforce hook exists). v0.7 collapses it to *install plugin → run one command*.

## 2. The hard constraint that shapes everything (doc-verified)

1. Claude Code runs NO script on plugin install (only-`Setup`-hook fires under `--init`, not on UI install).
2. A plugin CAN ship a `SessionStart` hook, but it can only inject `additionalContext` (no direct banner).
3. No first-run/PostInstall on UI install → DIY marker (a static path — see B3).
4. External-dep idiom = the LSP-plugin precedent ("install the binary separately first").

**∴ CEILING = install plugin → (SessionStart nudge) → user runs one `local-mcp setup`.**

## 3. Scope (narrow; review-hardened)

### 3.1 `local-mcp setup` — the one command (idempotent "fix-it button")

New commander subcommand in `bin/cli.ts`. Re-runnable; checks each state, skips what's done.

1. **Guard**: `detectHardware()` → arm64 + macOS, else fail fast. **Also RAM-gate (B4)**: read
   `totalMemoryGB`; gate the **8B (Tier C)** tier on **≥16 GB** (7.5 GB weights on an 8 GB Mac =
   swap-thrash). Do NOT block a 4B-only install on 8 GB.
2. **Engine** — **PIN A KNOWN-GOOD TAG, never `brew install` stable.** (2026-06-13 incident: the tap
   moved `stable` to a broken rc `0.4.4rc1` → every chat 500s `unicode-escape`; a bare
   `brew install jundot/omlx/omlx` gets a dead engine.) Build the chosen tag from its historical
   formula (`git -C "$(brew --repo jundot/omlx)" show <tag-bump>:Formula/omlx.rb` → `brew install` →
   `brew pin`). **Consent-gate the brew install (FORK C-b)** ("Install oMLX via Homebrew? source build
   ~2 min [Y/n]"). **Refuse to auto-install Homebrew itself (FORK C-d)** — if `brew` missing, fail with
   a brew.sh link. **Brew hardening (unanimous)**: `HOMEBREW_NO_AUTO_UPDATE=1` (kill the stealth
   multi-min update hang), Xcode-CLT preflight (`xcode-select -p`), brew-lock/contention detect +
   clear retry, surface expected build time.
3. **Models** — reuse `download-models` (B+C). **Consent gate** for the 7.5 GB (`[y/N]` + size + free
   disk + target); `--yes` for headless. **Real resume/integrity (B1)**: current `download-models.mjs`
   skips on `existsSync(target)` → an interrupted HF snapshot is treated as complete and never
   repaired. Fix: write a per-model `.complete` marker (or manifest size/SHA check); on a dir present
   without the marker, delete-and-retry — do NOT claim resume until this exists.
4. **Config** — write `~/.omlx/settings.json`; **PIN the port; ALL components read it from settings,
   never hardcode 8000 (FORK B)**. Default 8000 only if settings absent. **Collision = detect occupant
   (`lsof`), REFUSE to clobber, instruct** ("stop X or change port") — do not auto-reassign (dynamic
   auto-scan deferred as a later option). Atomic temp+`mv`; merge-don't-clobber a custom settings.
   NB `omlx serve --port N` persists the port into settings — pass the configured port, never a stray one.
5. **Start**: `brew services start jundot/omlx/omlx`; poll `/v1/models` (bounded).
6. **Mark + verify**: write a **static** setup-done marker `~/.omlx/.mcp-setup-done` (B3 — NOT
   `${CLAUDE_PLUGIN_DATA}`, undefined in the user's terminal) → run `local-mcp doctor`.

Flags: `--yes`, `--no-models`, `--models`. (`--no-models` is an intentional engine-only path for
BYO-weights/4B-only — not a "broken half-state"; doctor reporting "models missing" then = success.)

### 3.2 `local-mcp doctor` — prove the stack end-to-end

Layered; reports WHICH stage failed + log path + a copy-pasteable fix. **The load-bearing rule
(PA + the 2026-06-13 incident both): a `/v1/models` liveness ping 200s even when chat is fully
broken — so doctor MUST send a REAL chat request.**

- arch arm64+macOS; RAM; brew formula linked; **oMLX version is the pinned good tag**
- `~/.omlx/settings.json` exists; read the configured port; not stolen (`lsof`)
- **weight integrity (B5)**: tier models present + **size-vs-manifest** (catches truncated downloads),
  not just `existsSync`
- **THE PROOF**: a real `chat` with `response_format:{json_schema,strict}` AND a **fixed-prompt golden
  output** check (B5 — valid JSON ≠ uncorrupted weights). `--deep` = full per-tier round-trip + SHA.
- reuse `smoke:cross-client` for the stdio leg (verify "Claude↔bridge" separately from "bridge↔oMLX").

### 3.3 SessionStart nudge hook (gentle, never blocking) + enforce-hook gating

Add `SessionStart` to `hooks/hooks.json` → tiny `${CLAUDE_PLUGIN_ROOT}/.claude/hooks/setup-nudge.sh`:
a fast check (static marker `~/.omlx/.mcp-setup-done` / a sub-second `/v1/models` ping using the
configured port; dependency-light — `curl -s -o /dev/null -w %{http_code}` / `nc`, no `jq`); if not
ready, inject `additionalContext` so Claude suggests `local-mcp setup`. **Gentle/once-with-backoff,
never work-blocking** (rejected the fanout's "refuse all tasks" — the bridge is optional).

**B2 (must-fix)**: the plugin ships the `enforce-bridge.sh` PreToolUse(Read) hook, which fires on
install **before** setup → a user who skips setup gets large-Read blocks routed to bridge tools that
throw `ECONNREFUSED`, NOT the promised "run setup" copy. **Gate the enforce hook on the setup-done
marker** (default-off until `doctor` passes), else the plugin is worse than not installed pre-setup.

### 3.4 Distribution — route **α** (Auditor 2026-06-13, flipped from β)

**The adversarial review flipped the earlier β (npx) choice → A1/α, 6:1.** Ship the **built `dist`**
inside the plugin; `.mcp.json` launches `${CLAUDE_PLUGIN_ROOT}/packages/core/dist/bin/cli.js serve`
(already the current wiring). The structural fix for the long-deferred blocker (`dist` is gitignored):
**un-gitignore `dist` on the plugin release tag/branch** (a built-artifact release), so a stranger who
installs the plugin gets a runnable binary.

Why α beat the alternatives (all four constraints — starts-at-install-before-setup, fully-offline,
version-pinned-to-plugin, works-on-a-stranger's-machine):
- **A2 (β'-pinned-global `npm i -g`)**: a global install IS setup work → the MCP server can't start at
  plugin-install time (chicken-and-egg); also needs the user's node/npm. (Lone dissenting voice.)
- **A3 (β-pinned-npx)**: `npx` still hits the registry on a cache miss → breaks offline (the product's
  core value prop) + per-session cold-start latency.
- **α cost** = committing build artifacts on a release tag — "a trivial price for offline reliability;
  this is a plugin, not a library" (6 voices).

`serve` already fails gracefully when oMLX is down (MlxHttpBackend circuit-breaker) — but per B2 it must
surface "run `local-mcp setup`", not raw ECONNREFUSED.

## 4. Out of scope

Multi-client auto-config (documented manual only). Non-Apple-Silicon. Auto-installing Homebrew itself
(FORK C-d). Dynamic port auto-scan (deferred; fixed+refuse for v0.7). Model auto-update. Telemetry.
`local-mcp uninstall` (deferred, YAGNI).

## 5. Decisions (Auditor 2026-06-10 + adversarial review 2026-06-13)

- **FORK A (distribution) → α** (ship built dist; `.mcp.json` → `${CLAUDE_PLUGIN_ROOT}/.../dist`).
  Flipped from β. 6:1. §3.4.
- **FORK B (port) → fixed 8000 + read-from-settings everywhere + collision-detect-and-refuse**;
  dynamic auto-scan deferred. (Unanimous: never hardcode 8000.) §3.1.4 / §3.2.
- **FORK C (brew) → b + d**: consent-gate the oMLX brew install; refuse to auto-install Homebrew itself;
  + hardening (`HOMEBREW_NO_AUTO_UPDATE=1`, CLT preflight, lock-detect, show build time). §3.1.2.
- **B1–B5 (all 7 voices AGREE — must-fix)**: B1 real download resume/integrity (§3.1.3); B2 gate the
  enforce hook on setup-done (§3.3); B3 static marker `~/.omlx/.mcp-setup-done` (§3.1.6); B4 RAM-gate 8B
  ≥16 GB (§3.1.1); B5 doctor weight-integrity + golden-output (§3.2).
- **Engine policy → PIN a known-good TAG + probe real chat** (NOT brew stable, NOT `/v1/models`
  liveness). Empirically forced by the 2026-06-13 `0.4.4rc1` unicode-escape incident. §3.1.2 / §3.2.
- **Dropped as OVERBLOWN**: "<2s state-check unrealistic" (scoped to re-runs); "offer to auto-install
  Homebrew" (invasive/out-of-scope); "--no-models half-state" (intentional engine-only path).
- **Nudge cadence → once-with-backoff** [PM]. **Release vehicle → own v0.7.0** (β route would've forced
  a publish anyway; α ships dist on a tag) [PM].
